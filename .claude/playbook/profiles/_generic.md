# 과목 무관 코어 프로파일

> 어떤 과목이든 공통으로 지키는 규칙. 과목별 프로파일은 이 문서를 **덮어쓰지 않고 추가**한다.

---

## 산출물 원칙

| 원칙 | 이유 |
|---|---|
| **단일 HTML 파일로 완결** | 드라이브·Netlify·Pages 어디에 올려도 동작 |
| **모든 이미지 base64 임베드** | 외부 참조는 배포 시 반드시 깨진다 |
| **외부 의존은 CDN 2개까지** (MathJax·Tailwind) | 오프라인에서도 내용은 읽힌다 |
| **학생용은 정답 비노출** | 클릭·토글로만 확인 |
| **교사용은 학생용에서 기계 변환** | 손으로 만들면 동기화가 깨진다 |

---

## 난이도 체계 (기본값)

| 라벨 | 키 | 성격 |
|---|---|---|
| 기초 | `basic` | 정의·공식 직접 적용 |
| 기본 | `standard` | 조건 해석 + 도구 선택 |
| 도전 | `advanced` | 복합·역방향·구조 파악 |

- 한 단원당 **기초 3 / 기본 6 / 도전 2~3** 이 이번 사이클의 실제 비율이었다
- 라벨은 **화면에 배지로만** 노출. 내부 분류 코드는 노출하지 않는다

---

## 문항 데이터 스키마

```js
{
  id: 'u1-b1',                 // 단원키-난이도-번호
  level: 'basic',              // basic | standard | advanced
  levelLabel: '기초',
  num: 1,
  type: 'short',               // short | choice
  subLabel: '유형명',           // 짧게. 화면에 배지 옆에 뜬다
  title: '문항 제목',
  question: `<p>...</p>`,      // 그림은 여기에 base64로

  // type에 따라 정답 필드가 다르다 ★
  answerText: '\\(9\\)',       // short
  answer: 3,                   // choice — 0부터의 인덱스
  choices: ['①...', ...],      // choice — 각 20자 이내

  keypoint: '이 문제의 급소 한 줄',
  steps: [ { tag:'STEP 1', title:'...', body:`...` } ]
}
```

---

## 해설 작성 원칙

1. **STEP은 "무엇을"이 아니라 "왜"를 적는다**
   - ❌ "양변을 미분한다"
   - ✅ "적분식이 보이면 미분부터 — 적분과 미분이 역연산이라 왼쪽이 곧바로 f(x)가 된다"
2. **마지막에 흔한 오답 경로를 명시한다**
   - "부호를 무시하면 2/3(변위)이 나옵니다. 거리는 1입니다."
3. **단축법은 정공법과 나란히 보여 준다.** 정공법 결과와 일치함을 확인시켜야 학생이 쓴다
4. **교육과정 밖 도구는 본 풀이에서 빼고 별해로 남긴다**

## 수식 표기

| 규칙 | 예 |
|---|---|
| 인라인 `\( \)`, 디스플레이 `\[ \]` | |
| **부등호는 `\lt` `\gt` `\le` `\ge`** ★ | `\(a\lt b\)` |
| 분수는 `\dfrac` (인라인에서도 크게) | |
| 백슬래시는 빌드 스크립트에서 **이중** | `'\\(9\\)'` |

## 레이아웃 폭

- **한 섹션 안에서는 폭이 흔들리지 않게** 한다 (DECISIONS D-12)
- 문항 카드는 **전폭 1단**. 그리드 항목에는 `min-width: 0` 을 준다
  (없으면 넓은 수식이 카드를 통째로 늘려 측정까지 속인다 — PITFALLS C-8)
- **통합본과 개별 파일의 카드 폭을 같게** 맞춘다. 다르면 개별에서 통과한 검증이 무효가 된다
- 카드 폭은 고정하고, 안 들어가는 **수식이 양보**한다 (`font-size` 축소, `transform` 금지)

## 인쇄

| 모드 | 레이아웃 | 정답 |
|---|---|---|
| 문제만 | 세로, 흐름대로 | 숨김 |
| 문제 + 필기공간 | **화면 모달과 동일한 좌우 분할**, 가로 | 숨김 |
| 문제 + 해설 | 세로, 흐름대로 | 표시 |

- 문항 컨테이너에 `break-inside: avoid`
- **인쇄 미디어에서 실제 높이를 측정**해 페이지 초과를 확인
- **`overflow: auto` 는 인쇄에서 내용을 삼킨다** — 인쇄 블록에서 `overflow: visible` 로 (PITFALLS C-5)
- 여백·구분선은 가상 요소가 아니라 **실제 DOM 요소**로 (iOS Safari 대응)

## 접근성 · 기기

- 전자칠판(대형) / 태블릿(필기) / PC 세 곳에서 쓴다
- 터치 대상은 최소 34px
- 다크 모드 대응 (전자칠판 야간 수업)
- 인쇄는 **PC와 태블릿에서 각각** 확인 (엔진이 다르다)

## 명명 규칙

```
<자료종류>_<과목>_<단원키>_<단원명>_<용도>.html

학습지_미적분I_04_중단원마무리_I_1.html
수학익힘책_미적분I_I1_함수의극한_해설.html
교사용_수학익힘책_미적분I_I1_함수의극한_해설.html
교사용_Nav_수학익힘책_미적분I_I1_함수의극한.html
```

- 교사용은 `교사용_` 접두
- 수업 가이드는 `교사용_Nav_` 접두
- **접두어를 빠뜨리면 링크가 깨진다** (실제 사고 사례 있음)
