## 자주 쓰는 계산 단축법

정공법과 **나란히** 제시한다. 결과가 같음을 보여야 학생이 신뢰한다.

| 상황 | 단축 |
|---|---|
| 두 이차곡선 사이 넓이 | `S = |k|/6 · (β−α)³` |
| 대칭구간 정적분 | 기함수(홀수 차항) → 0, 짝수 차항만 `2∫₀ᵃ` |
| 역함수 정적분 | `∫ₐᵇf + ∫_c^d g = bd − ac` (단, f(a)=c, f(b)=d) |
| 삼차함수 중근 | `f(b)=f'(b)=0` ⟹ `f = k(x−a)(x−b)²` |
| 미정형 극한 | 분모→0 ⟹ **분자도→0** |

## 오답 유도 포인트 (해설 `hint`에 넣을 것)

| 단원 | 대표 함정 |
|---|---|
| 극한 | 조임정리에서 **양 끝 극한이 같은지** 확인 안 함 |
| 극한 | 합성함수에서 안쪽 변수의 **접근 방향**(좌/우) 누락 |
| 연속 | 분모가 **중근**인데 "분자→0" 조건을 한 번만 적용 |
| 연속 | "적어도 n번"의 의미 — 사잇값이 보장하는 **최소** 횟수 |
| 미분 | **연속 ≠ 미분가능** (꺾인 점) |
| 미분 | 정의꼴 변형 시 **보정 인수** 누락 |
| 도함수 활용 | 부등식 문제에서 **정의역 조건** 무시 |
| 도함수 활용 | 원까지 최단거리에서 **반지름 빼기** 누락 |
| 적분 | 미분 후 `f`가 안 나오면 **한 번 더** 미분해야 함 |
| 적분 활용 | **위치(∫v) vs 거리(∫\|v\|)** ← 이 단원 오답 1위 |
| 적분 활용 | 곡선이 x축 **아래**일 때 부호 뒤집기 |

## 그림 처리

- **원본 캡처 우선.** SVG로 다시 그리면 원본과 미묘하게 달라져 혼란을 준다
  (실제로 SVG → 원본 PNG로 되돌린 사례가 있다)
- 크롭 해상도 **300 dpi**
- 화면 `max-width: min(100%, 420px)` / 인쇄 `320px`
- 크롭 후 **반드시 눈으로 확인**

## 난이도 판정

문제집은 **페이지 상단 탭이나 단 구분**으로 난이도를 표시한다.
텍스트 추출 순서로는 판정할 수 없다.

```python
doc[i].get_pixmap(dpi=110).save(f'page{i}.png')   # 렌더해서 직접 본다
```

> 실제 사례: 텍스트 순서는 `기본 → 도전 → 기초 → 기초 → 도전 → 기본` 이었는데,
> 실제로는 **좌측 단 = 기초 3문항, 우측 단 = 기본 3문항** 이었다.

## 수식 폭

수학 문서는 **긴 수식이 카드를 넘는 일이 잦다.** 이번 사이클 실측:

- 전체 수식 17,905개 중 임계 초과 **66개 (0.4%)** — 드물지만 눈에 띈다
- 최장 수식 근사 89자 ≈ 670px
- 삼중곱 미분·곱의 미분법 전개처럼 **한 줄에 등호가 3개 이상** 이어지면 위험하다

대응은 `_generic.md` 의 레이아웃 폭 원칙을 따른다 — **폭 고정, 수식이 양보**.
