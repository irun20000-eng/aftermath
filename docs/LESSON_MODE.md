# 수업 모드 (전자칠판용) — 미적분 I 1~31차시 적용

> 학습지를 아래로 스크롤하며 진행하던 방식을 **탭 + 한 화면 단위 + 판서 공간**으로 바꾼다.
> 판서는 전자칠판 **필기모드**(화면 캡처 후 필기)로 한다. 페이지 안에는 펜 기능이 없다.
> 대신 판서 계획의 **판서 예시를 눌러서 한 줄씩** 띄울 수 있다 (아래 ‘판서 예시 단계 공개’). 띄운 뒤 필기모드로 덧쓰면 된다.
> 적용 차시: 1~31 전 차시 (19차시 파일럿 → 18~31 → 1~17 순으로 적용).

## 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 바 | 차시명 · 탭(시간 표시 포함) · **반 ▾** · 타이머(**이 단계 N′** · 1·3·5분) · **🎲 1명** · 뽑기 창 · **판서 ▾** · 나가기 |
| 왼쪽 절반 | 학습지 본문을 **한 화면에 한 단위**로 — 개념 블록 1개, 문항 1개씩. 글자 크기 자동 맞춤(스크롤 없음). 머리에 **정답·풀이 열기** · 진행률(예: 3/5 · 전체 7/17) |
| 오른쪽 절반 | 흰 판서 공간. 판서 계획의 구역 ①②③ 틀과 제목을 흐리게 표시. 판서 예시는 숨겨 두고 누르면 한 줄씩 · 아래에 공개 조작 막대 |

- **반 ▾**: 1·4·7·10반. 반마다 "어디까지 했는지"를 따로 기억해서, 반을 바꾸면 그 반이 멈춘 화면으로 간다 (브라우저 localStorage).
- **이 단계 N′**: 지금 탭의 타임라인 시간으로 타이머를 바로 시작 (판서 계획의 `minutes`, Nav 타임라인에서 계산).
- **🎲 1명**: 뽑기 창을 거치지 않고 지금 반에서 1명을 바로 뽑는다. 누를 때마다 한 명씩 추가, 결과 [확인]을 누르면 창이 닫히고 수업 화면으로 돌아온다. **뽑기 창**은 모둠 뽑기·인원 설정·결석 표시용.
- **정답·풀이 열기**: 그 화면의 `?` 정답 상자와 힌트·풀이를 한꺼번에 열고 닫는다.
- **판서 ▾**: 배경(빈칸·모눈·좌표) · 구역 틀 · 판서 넓게 · (판서 예시) **→ 키로 한 줄씩** · **그래프 개형**.
- 켜기: 학습지 상단 **[수업 모드 ▶]** · 주소 뒤 `?mode=class` · 인덱스 버튼 (교사용 인덱스는 차시를 누르면 바로 수업 모드, 옆의 **일반 보기**는 스크롤 학습지)
- 바로가기: `#lm=<탭키>.<번호>` (예: `#lm=level.7`)
- 키: ←/→, PageUp/PageDown(프레젠터) · 1~6 탭 · 수업 중에는 Esc/H 로 메인에 나가지 않는다
- 나가기·인쇄하면 원래 학습지로 그대로 돌아간다 (본문 HTML 은 바뀌지 않음)
- 좁은 화면(노트북)에서는 상단 바가 두 줄이 되고, 세로 화면은 본문 위·판서 아래로 배치된다.

## 판서 예시 단계 공개

판서 계획(`boardplans/calc_NN.js`)의 `zones[].ex` 를 판서 공간에 **숨겨 두고** 필요할 때 띄운다. 새 데이터는 없다 — 교사용 Nav 판서 예시와 같은 내용.

| 조작 | 동작 |
|---|---|
| 구역 누르기 | 그 구역의 다음 한 줄 |
| 구역 두 번 누르기 | 그 구역 전체 (되돌리기 한 번에 원래대로) |
| 아래 막대 | **◀ 이전 단계**(마지막으로 한 일 되돌리기) · **다음 줄 ▶** · 모두 보이기 · 모두 숨기기 · 공개 수(예: 3/8) |
| ↓ / ↑ | 다음 줄 / 이전 단계 (항상) |
| →·PageDown / ←·PageUp | 기본은 화면 이동. **판서 ▾ → 키로 한 줄씩** 을 켜면 파워포인트처럼 다음 줄 먼저, 다 보이면 다음 화면 (거꾸로도 같음) |

- 구역 제목 옆 `2/4` 는 그 구역에서 몇 줄 보였는지. 다 보이면 초록.
- 숨긴 줄도 자리를 차지한다 → 띄울 때 글이 밀리지 않는다. 글자 크기는 **구역마다** 넘치지 않는 가장 큰 크기(font-size, PITFALLS C-9).
- 좌표 구역: 글이 나오면 글은 왼쪽 · 좌표축은 오른쪽. 식이 길어 너무 작아지면 글을 위, 그래프를 아래로.
- **그래프 개형**(기본 꺼짐): 켜면 `plot` 이 있는 구역은 마지막 단계에 개형이 나온다. 끄면 지금처럼 선생님이 그릴 빈 좌표축.
- 공개 상태는 화면마다 기억(다른 화면에 갔다 와도 그대로). **반을 바꾸면 처음부터**, 새로고침하면 초기화. 두 설정(→ 키 · 그래프)은 브라우저에 기억(`lm:pref`).
- 구역 틀을 꺼도 이미 띄운 판서 예시는 남는다. 판서 예시가 있는 화면에서는 오른쪽 위 출처 표시가 한 줄(전체는 왼쪽 머리줄).
- 자동 검사용: `window.aftLessonMode.reveal` (`next` · `back` · `undo` · `all` · `none` · `totals` · `ready`).

## 판서 계획 작성 규칙 (A안)

- 생각 열기·개념·성찰: Nav D 판서 시연·오개념과 학습지 본문으로 직접 설계.
- 문항 화면: Nav 해설 카드 풀이 단계를 2~3구역(조건·식 → 핵심 계산 → 답·함정)으로 재구성. 해설에 없는 풀이는 넣지 않는다.
- 판서 예시의 수치는 모두 독립 재계산으로 확인한다. 원문과 다르면 별도 검증 후 원문을 고친다 (`docs/CONTENT_FIXES_2026-10.md`).
- 색: 줄 앞 `b:` 핵심 결과 · `r:` 함정 · `g:` 학생 답 · 없음 기본 식. 줄 중간은 `[[b:…]]`.
- 그래프: 구역에 `axes`, 교사용 예시에만 `plot`(개형). 판서 계획 문장은 글자 그대로 표시된다 (`<` 도 안전).

## 교사용 Nav

학습지와 같은 탭 순서: 개관 · 생각 열기 · 개념 구성 · 수준별 훈련 · 형성평가 · 도전 · 성찰·메모
(마무리·평가 차시: 개관 · 실전 훈련 · 성찰·메모). 각 탭에 시간 → 운영 가이드 → 문항 해설 → **판서 예시**(+ [수업 화면 열기]).
**수업 중 보기**: 판서 예시·타임라인만 크게 (태블릿·보조 화면). 인쇄(A4)하면 모든 탭이 차례로 나온다.

⚠️ `build_nav_tabs.py` 는 main 의 Nav 에서 다시 만든다. 이 브랜치에서 Nav 문장을 고친 차시(내용 오류 수정)는 **다시 돌리지 않는다**.

## 학생 뽑기 — 간단 1단계 (`뽑기_미적분I.html`, `뽑기.html` 공통)

- 모드 맨 앞 **⚡ 간단 1단계**: 반 전체(출석) 학생에서 **정한 인원만큼** 바로 뽑는다.
- 뽑는 인원: −/+ 또는 1·2·3·4·6. **학습리더 포함** 켜기/끄기. **＋1명 더**: 방금 뽑힌 학생을 빼고 한 명 추가.
- 공정 추첨·누적 기록·라운드 초기화·모드 전환 롤백은 기존 모드와 같게 동작. 단축키 `1` 뽑기 · `2` 한 명 더 · `+`/`-` 인원.
- 화면 설정(모드·인원·리더 포함)은 브라우저에 기억. 누적 기록·결석은 기존 방식 그대로.
- 수업 모드용 API: `window.aftPicker.setClass(n)` · `window.aftPicker.quick(n, 반)`.

## 새 차시를 추가할 때

1. 학습지·교사용 사본에 `lesson-mode.css/js` + `boardplans/calc_NN.js` 포함 (18~31과 같은 방식).
2. 판서 계획 작성 (A안) → 수학 재검산 → 불일치는 독립 검증 후 원문 수정.
3. `python3 scripts/build_nav_tabs.py NN …` 로 Nav 변환 (마무리 차시 04·07·08·11 은 실전 훈련 구조).
4. 인덱스 3곳에 수업 모드 버튼 (교사용 인덱스는 기본 링크를 수업 모드로).
5. 통합본(`build_bundle_calc.py`)에서는 수업 모드가 스스로 꺼진다(헤더 2개 이상).

## 통합본 생성

- `python scripts/build_teacher_bundles.py` → `교사용/교사용_Solutions_All_미적분I.html`(해설 모음)과 `교사용/교사용_Nav_All_묶음_미적분I.html`(Nav 통째 묶음)을 Nav 정본에서 다시 쓴다. 두 파일은 손으로 고치지 않는다.
- **언제 다시 돌리나: Nav(`교사용_Nav_*.html`)나 `boardplans/calc_NN.js` 를 고친 뒤.** 실행하면 이전 파일 대비 차시별 변화(카드 수 · 문항 문장/정답이 달라진 카드 번호)를 출력한다. `--detail L17` 은 카드별 원문 비교, `--base main` 은 main 판과 비교, `--dry-run` 은 쓰지 않고 요약만.
- Solutions_All: 외형(표지·목차·CSS)은 그대로, 차시 머리·한 줄 핵심·공식 박스·문항 해설 카드 전부를 Nav 에서 가져온다. '다음 차시' 한 줄은 Nav 에 없어 기존 파일 것을 이어 쓴다.
- Nav_All 묶음: 탭 바를 빼고 모든 패널을 펼친다. 판서 칠판은 `window.LM_BOARD_PLANS['NN']` + `[data-lesson]` 으로 차시마다 자기 계획을 쓴다 (`lesson-board.js` 는 LM_BOARD_PLANS 가 없으면 예전처럼 LM_BOARD_PLAN 하나).
- 돌린 뒤 `verify_links.py`(중복 id 0) · `verify_lesson_mode.py` 를 다시 돌린다.
