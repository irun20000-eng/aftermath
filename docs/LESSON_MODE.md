# 수업 모드 (전자칠판용) — 파일럿: 미적분 I 19차시

> 학습지를 아래로 스크롤하며 진행하던 방식을 **탭 + 한 화면 단위 + 판서 공간**으로 바꾼다.
> 판서는 전자칠판 **필기모드**(화면 캡처 후 필기)로 한다. 페이지 안에는 펜 기능이 없다.

## 화면 구성

| 위치 | 내용 |
|---|---|
| 상단 바 | 차시명 · 탭(생각 열기 / 개념 구성 / 수준별 훈련 / 형성평가 / 도전 / 성찰) · 타이머(1·3·5분) · 학생 뽑기 · 판서 배경(빈칸·모눈·좌표) · 구역 틀 · 판서 넓게 · 나가기 |
| 왼쪽 절반 | 학습지 본문을 **한 화면에 한 단위**로 — 개념 블록 1개, 문항 1개씩. 글자 크기를 자동으로 맞춰 스크롤이 생기지 않게 한다 |
| 오른쪽 절반 | 흰 판서 공간. 차시별 판서 계획이 있으면 구역 ①②③ 틀과 제목을 흐리게 표시 |

- 켜기: 학습지 상단 **[수업 모드 ▶]** 버튼 · 주소 뒤 `?mode=class` · 인덱스의 **수업 모드** 버튼
- 바로가기: `#lm=<탭키>.<번호>` (예: `#lm=level.7` = 수준별 훈련 7번 화면)
- 키: ←/→, PageUp/PageDown(프레젠터) 이전·다음 · 1~6 탭 이동 · 수업 중에는 Esc/H 로 메인에 나가지 않는다
- 끄기(나가기)·인쇄하면 원래 학습지로 그대로 돌아간다 (본문 HTML 은 바뀌지 않음)

## 파일

| 파일 | 역할 |
|---|---|
| `lesson-mode.js` / `lesson-mode.css` | 수업 모드 본체 (학생용·교사용 학습지 공용, `교사용/` 에 사본) |
| `boardplans/calc_19.js` | 19차시 판서 계획 — 화면별 구역 제목 + 교사용 판서 예시 (`교사용/` 에 사본) |
| `교사용/lesson-board.js` / `.css` | 교사용 Nav 의 탭 전환 + 판서 예시 미니 칠판 |

판서 계획 한 파일을 두 곳에서 쓴다. 학습지에는 **구역 제목만**, 교사용 Nav 에는 **무엇을 어떤 색으로 쓸지**까지 나온다.
색 약속: 검정 기본 식 · 파랑 핵심 결과 · 빨강 함정·주의 · 초록 학생 답·발표.

## 교사용 Nav (19차시)

학습지와 같은 탭 순서로 재구성: 개관 · 생각 열기 · 개념 구성 · 수준별 훈련 · 형성평가 · 도전 · 성찰·메모.
각 탭에 시간 배분 → 운영 가이드 → 문항 해설 → **판서 예시**(수업 화면 바로 열기 링크 포함)가 이어진다.
인쇄(A4)하면 모든 탭이 차례로 나온다.

## 다른 차시로 넓힐 때 (아직 하지 않음)

1. 31개 학습지 모두 `widgets.js` 를 불러오므로, 확정 후에는 `widgets.js` 가 `lesson-mode.js` 를 불러오게 하면 한 번에 적용된다 (PITFALLS B-1).
2. 판서 계획(`boardplans/calc_NN.js`)은 차시마다 작성한다. 없으면 구역 틀 없이 빈 판서 공간만 나온다.
3. 마무리·평가 차시(04·07·08·11·20·21·25·29·30·31)는 "실전 훈련" 한 섹션이라 문항 단위로 자동 분할된다.
4. `scripts/build_bundle_calc.py` 로 통합본을 다시 만들 때 lesson-mode 스크립트는 통합본에서 스스로 꺼진다(헤더가 2개 이상이면 동작 안 함).
